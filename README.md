# Proposta de Implantação de Cultura — INETRIS × Grande Rede Telecom

Página única (`index.html`), autocontida: imagens e estilos estão embutidos no arquivo.

## Publicar no GitHub Pages
1. Suba estes arquivos na raiz do repositório.
2. Em **Settings → Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
3. A página ficará disponível em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
